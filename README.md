# Upstox Option Chain & Volume Analytics

Yeh ek real-time Nifty Option Chain aur Volume analytics dashboard hai, jise Python, Streamlit, aur Upstox API v2 ka use karke banaya gaya hai. Isse aap live Open Interest (OI) aur Volume spikes ke zariye major Support aur Resistance zones track kar sakte hain.

## Features
- **Live Data Fetching:** Upstox API se direct real-time option chain data retrieve karta hai.
- **Key Metrics:** Major Resistance (Max Call OI), Major Support (Max Put OI), aur Highest Volume strikes automatically calculate karta hai.
- **Interactive UI:** Streamlit par bana clean aur fast web dashboard.
